# High School Senior Portfolio 🎓

This repository contains my personal portfolio website created during my senior year of high school to fulfill a graduation requirement. 

While this site is no longer active or actively maintained, I keep this repository public as a personal milestone: I built it from scratch with **zero formal web development education** and minimal AI assistance, teaching myself HTML, CSS, and JavaScript along the way.

---

### Overview

* **Purpose:** High School Senior Graduation Requirement & Personal Portfolio
* **Tech Stack:** HTML5, CSS3, JavaScript
* **Deployment:** [GitHub Pages](https://github.com/samanthadiggs/hs_senior_portfolio)
* **Status:** Archived / Inactive

---

### What I Learned

Building this site was my introduction to web development. Key areas I tackled include:
* Structuring multi-page Web layouts (`about.html`, `portfolio.html`, `education.html`, `credits.html`)
* Basic interactive elements using custom JavaScript and frameworks such as GSAP
* Custom styling, animations, and visual layouts with CSS
* Version control and deploying static sites via GitHub Pages
